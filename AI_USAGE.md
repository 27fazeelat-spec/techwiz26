# AI Usage Declaration

AI-assisted tools were used during the development of SkillSprint for limited support activities. AI assistance was used in preparing and structuring the project dataset, including the creation and organization of the 185+ requirement records and supporting sample documents. AI assistance was also used during development when specific UI, backend, debugging, or implementation issues required additional guidance.

## AI-Assisted Development Details

### 1. Tool

AI-assisted generative AI tools were used for development support and dataset preparation.

### 2. Purpose

The assistance was used for:

* Preparing and structuring the project dataset.
* Creating and organizing the 185+ requirement records and supporting sample documents.
* Providing guidance for specific UI issues.
* Providing backend and implementation guidance.
* Supporting debugging and troubleshooting.

### 3. Prompt or Assistance Type

The assistance included dataset-generation guidance, structuring assistance, UI suggestions, backend guidance, debugging support, troubleshooting, and implementation guidance.

### 4. Files Affected

AI assistance primarily affected the project dataset, supporting sample documents, and selected UI/backend project files where development guidance was applied.

### 5. Modifications Made

AI-assisted outputs were reviewed by the project team and modified, adapted, integrated, or rewritten where required. No complete AI-generated source code was submitted without independent review and adaptation.

### 6. Tests Performed

AI-assisted changes were independently reviewed, debugged, and tested through functional testing, project-level validation, and relevant application testing before being incorporated into the final project.
