## 1. Purpose and scope

### 1.1 Purpose

Aurelle holds personal data about guests and employees, payment information and commercially sensitive rates. This policy sets the baseline security behaviour that protects that information across all properties.

### 1.2 Scope

The policy covers every person with an Aurelle account: employees, trainees, contractors and agency staff, on company or enrolled personal devices.

## 2. Security awareness

### 2.1 Basics training

All employees must complete the Information Security Basics e-learning module before being granted access to any Aurelle system.

### 2.2 Refresher training

The Basics module is refreshed every year, with short monthly awareness messages on the staff intranet.

## 3. Accounts and passwords

### 3.1 Password standard

Passwords must be at least 12 characters long and must be changed immediately if compromise is suspected.

### 3.2 Password manager

Aurelle provides a corporate password manager for colleagues who use several systems. Passphrases made of four or more unrelated words are both strong and easy to remember.

### 3.3 Multi-factor authentication

Multi-factor authentication must be enabled for email and for the Property Management System (PMS) before first use.

### 3.4 Authenticator app

The approved authenticator app is installed during IT onboarding. Hardware tokens are available for colleagues without a smartphone.

### 3.5 Personal accounts

Users must never share login credentials; every action in the PMS must be performed under the user's own account.

## 4. Workstations

### 4.1 Shared terminals

Front desk and outlet terminals are shared between colleagues on the same shift, which makes personal log-in and log-out especially important.

### 4.2 Locking screens

Workstations must be locked whenever they are left unattended.

## 5. Email

### 5.1 Phishing

Suspected phishing emails must be reported using the Report Phishing button and must not be forwarded to colleagues.

### 5.2 Common signs

Phishing messages often create urgency, imitate senior managers or suppliers, and link to login pages that look almost identical to Aurelle systems.

## 6. Data handling

### 6.1 Classification

| Class | Examples | Storage |
|---|---|---|
| Public | Published rates, brochures | Any Aurelle system |
| Internal | Rotas, procedures | Aurelle systems only |
| Confidential | Guest and employee personal data, card data | Approved systems only, access by role |

### 6.2 Removable media

Guest or employee personal data must not be copied to USB drives or personal cloud storage.

## 7. Incidents

### 7.1 Reporting

Any suspected security incident must be reported to the IT Service Desk immediately.

### 7.2 Examples

Examples include a lost laptop or phone, an email sent to the wrong guest, an unknown person in a back-office area, or a colleague's password written on a sticky note.
