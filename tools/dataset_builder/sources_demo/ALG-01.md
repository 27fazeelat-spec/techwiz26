## 1. Taking the order

### 1.1 Marking the ticket

Allergy orders must be marked with a purple flag on the kitchen ticket and prepared on a separate, clean board.

### 1.2 Confirming

The server must repeat the allergy back to the guest before sending the order.

## 2. In the kitchen

### 2.1 Utensils

Line cooks must use clean utensils and a clean pan for every allergy order.

### 2.2 Swaps

Ingredients in an allergy dish must not be swapped without telling the server and the guest.
