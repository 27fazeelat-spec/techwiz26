## 1. How we work

### 1.1 Uniform

All employees must wear a clean uniform and name badge on every shift.

### 1.2 Phones

Personal phones must not be used in food preparation areas.

## 2. Respect

### 2.1 Harassment

Harassment of any kind must be reported to a shift supervisor or the People team within 24 hours.

### 2.2 Gifts

Gifts from suppliers worth more than 25 USD must be declared to the shift supervisor.

## 3. Acknowledgement

### 3.1 Reading this code

Every new employee must read and sign this Code of Conduct on the first day.
